01 / The problem

A shortlist can score well
and still be hard to trust.

With thousands of probes and only 72 samples, feature rankings can shift, repeat the same signal, or lose the biological relationships behind the measurements.

01 · Stability

Rankings can change across splits

A different training subset may return a different shortlist, making it difficult to know which features are dependable.

02 · Redundancy

Many probes can repeat one signal

Highly correlated features may crowd the selected set without adding much new information.

03 · Biological context

Independent scores miss pathway groups

Scoring each probe alone does not represent how several genes participate in the same pathway.

04 · Leakage

Test data must not guide selection

If feature rankings use held-out samples, reported evaluation can look better than a valid unseen-data estimate.

Design target: a compact, interpretable shortlist evaluated with training-fold-only feature selection. These are the problems the pipeline is designed to address; the current demo does not claim they are all solved.
02 / Goal

Build a shortlist
that survives scrutiny.

Turn a high-dimensional expression matrix into a smaller set of informative probe features, while retaining pathway structure and an auditable selection process.

Structure

Use pathway relationships

Represent a pathway as one connection across its member probes, then combine that structure with class relevance.

Orchestration

Make each agent role concrete

Let agents plan and review candidate selections using structured outputs, while Python tools perform the actual matrix-based computation.

Explanation

Keep the evidence traceable

Carry selected probe IDs into pathway annotations and report evaluation metrics with the selection method.

Evaluation

Compare under the same protocol

Use the same data splits and metrics to examine balanced accuracy, redundancy, selection stability, and runtime.

Project question: can pathway context and structured review produce a more useful, explainable feature shortlist than selecting probes by individual scores alone?
03 / Novelty and intended use

The contribution is the connected workflow.

The project brings pathway-informed ranking, local selector tools, platform-aware biological context, and a four-role review graph into one inspectable research pipeline.

In scope

  • Compare selectors on shared folds, metrics, and evaluation budgets.
  • Fit preprocessing and feature ranking inside training folds.
  • Generate candidate shortlists locally, then review bounded evidence.
  • Use pathway and literature context with traceable identifiers.

Outside this prototype

  • Patient-level diagnosis, prognosis, or treatment selection.
  • Clinical deployment or claims of clinical validation.
  • Causal claims about gene mechanisms.
  • Evidence that one dataset proves generalization to every platform.
Data boundary: expression values and sample labels stay in local Python. Agents receive bounded summaries and selected IDs; NCBI/KEGG lookups use mapped identifiers for biological context.
System architecture · workflow

Local selection.
Bounded agent review.

The workflow separates matrix computation from agent reasoning and external biological lookups.

01 · Local data plane

Prepare the expression matrix

Load mapped probe IDs and labels; split samples for evaluation; fit preprocessing and selectors using training folds only.

02 · Candidate generation

Run selector tools in Python

Compute candidate feature sets with the configured selector families. Expression values and labels remain local.

03 · Agent review

Planner → Bio-Refiner → Challenger

Plan valid runs, inspect mapped biological context, and question weak evidence or limitations through Pydantic-validated state.

04 · Decision and record

Judge → selected candidate

Choose among executed candidates; if review reaches its revision limit, apply the documented fallback and record why.

Information boundary: agents receive bounded metadata, candidate IDs, and evaluation summaries. NCBI/KEGG lookups use mapped identifiers; no expression matrix is sent to the LLM.

02 / Why a hypergraph

Pathways connect groups, not just pairs.

A conventional graph links two nodes at a time. A hypergraph lets one pathway connect many gene probes in a single relationship.

373KEGG human pathways in the snapshot
4,555GPL80 probes with pathway membership
31,513probe-to-pathway memberships

The highlighted memberships are from the GPL80 annotation and cached KEGG relations. The diagram shows only a small slice.

Selector families · comparison

Three selector families.
One shared comparison.

Each family prioritizes features differently. Comparing them under the same evaluation setup helps show what pathway structure contributes.

Univariate · F-score

Rank by class separation

Score each probe independently by comparing between-class and within-class variation. It is a simple, fast reference point.

Redundancy-aware · mRMR

Balance relevance and repetition

Prefer probes that distinguish classes while avoiding candidates that strongly correlate with already selected probes.

Sparse model · L1 logistic

Use sparse model coefficients

L1 regularization can shrink some coefficients to zero; the remaining non-zero weights inform a compact feature set.

Pathway-aware · hypergraph

Include group structure

Combine class-relevance scores with centrality propagated through multi-gene pathway memberships.

Fair comparison: use the same folds, metrics, and feature budget for each selector. Their selection rules differ; evaluation conditions should not.

Pathway-aware feature ranking

Measure relevance.
Propagate through pathways.

Within each training fold, the selector combines a probe’s class-separation signal with its structural position in the pathway hypergraph.

1 · Measure class relevance

Training-fold ANOVA F-score

Calculate probe scores from training samples only, then normalize the scores to [0, 1].

2 · Propagate through memberships

Build and use incidence matrix H

Rows represent probes and columns represent pathways. Node and pathway degrees normalize how relevance moves across shared memberships.

3 · Blend and select

Combine signal with centrality

Normalize both components and rank probes by the weighted combined score, then keep the top k features.

Fold safety

Do not rank with held-out samples

Fit the relevance scores and selected feature list independently inside each training fold.

S = Dv−1/2 H De−1 Hᵀ Dv−1/2
r(t+1) = α S r(t) + (1 − α) f
score = (1 − w) fnorm + w cnorm
Configured example: α = 0.85 · w = 0.40 · 30 propagation iterations · k = 50. These settings describe this implementation; they are not universal defaults for every dataset.

The complementary score penalized candidates that repeated signals already represented in the selected set.

What it suggests

The selected set was less correlated while maintaining similar balanced accuracy on this benchmark.
